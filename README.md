# 账号出入库管理

命令行工具，用于管理账号库存：录入账号、按先进先出（FIFO）出库，并将出库内容自动复制到剪贴板。

## 功能

- **库存展示**：主菜单显示当前库存数量
- **账号录入**：支持 `----` 分隔格式，2～4 段字段
- **FIFO 出库**：按入库时间取出最早账号，格式化输出并复制到剪贴板
- **重复检查**：库存内账号直接拒绝；曾出库账号需二次确认
- **出库历史**：每次出库写入历史记录，保留入库/出库时间

## 环境要求

- Python 3.10+
- 仅使用标准库（SQLite、`tkinter` 用于剪贴板）

## 运行

```bash
python main.py
```

首次运行会自动创建 `data/accounts.db`。

## 使用说明

启动后进入交互菜单：

| 选项 | 说明 |
|------|------|
| `0` | 录入账号 |
| `1` | 出库账号（FIFO，自动复制到剪贴板） |
| `q` | 退出 |

也可按 `Ctrl+C` 退出。

### 录入格式

一行输入，字段用四个连字符 `----` 分隔：

```
账号----密码----邮箱----邮箱密码
```

- **前两段必填**：账号、密码
- **后两段可选**：邮箱、邮箱密码

示例：

```
user001----pass123
user002----pass456----mail@example.com----mailpass
```

### 重复账号处理

| 情况 | 行为 |
|------|------|
| 账号已在**库存**中 | 直接取消录入，不可覆盖 |
| 账号曾在**出库记录**中 | 显示警告及最近出库时间，询问 `是否仍要录入？(y/N)`；默认 `N` 取消，输入 `y` 才允许录入 |

### 出库

- 无库存时提示「当前无库存，无法出库」
- 有库存时取出最早入库的账号，打印并尝试复制到剪贴板（复制失败时需手动复制）

## 项目结构

```
.
├── main.py              # 入口：初始化数据库并启动 CLI
├── cli.py               # 交互菜单、录入/出库逻辑、剪贴板
├── database.py          # SQLite 读写
├── parser.py            # 账号行解析与格式化
├── test_verification.py # 自动化验证脚本
└── data/
    └── accounts.db      # 运行时自动创建
```

## 数据存储

数据库文件：`data/accounts.db`

| 表名 | 用途 | 主要字段 |
|------|------|----------|
| `accounts` | 当前库存 | `username`（唯一）、`password`、`email`、`email_password`、`created_at` |
| `outbound_records` | 出库历史 | 账号信息 + `inbound_at`（原入库时间）、`outbound_at`（出库时间） |

## 测试

```bash
python test_verification.py
```

脚本在临时数据库中运行，覆盖库存计数、重复拦截、FIFO 出库、出库历史确认、格式校验等场景。全部通过则退出码为 0。
