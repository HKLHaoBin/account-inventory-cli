# account-inventory-cli

> 账号出入库管理 — A Python CLI for account inventory management.

命令行工具，用于管理账号库存：录入账号、按先进先出（FIFO）出库，并将出库内容自动复制到剪贴板。

## 克隆

```bash
git clone https://github.com/HKLHaoBin/account-inventory-cli.git
cd account-inventory-cli
python main.py
```

## 功能

- **库存展示**：主菜单显示当前库存数量
- **账号录入**：支持 `----` 分隔格式，2～5 段字段
- **FIFO 出库**：按入库时间取出最早账号，格式化输出并复制到剪贴板
- **重复检查**：库存内账号直接拒绝；曾出库账号需二次确认
- **出库历史**：每次出库写入历史记录，保留入库/出库时间
- **失败复制**：批量录入结束后，自动将失败条目的原始行复制到剪贴板
- **账号查找**：子串匹配，先查库存再查出库历史

## 环境要求

- Python 3.10+
- 仅使用标准库（SQLite；Windows 优先用 Win32 剪贴板，`tkinter` 作 fallback）

## 运行

```bash
python main.py
```

首次运行会自动创建 `data/accounts.db`；若数据库已存在，会自动迁移添加 `url` 列。

## 使用说明

启动后进入交互菜单：

| 选项 | 说明 |
|------|------|
| `0` | 录入账号（支持多行批量，空行结束） |
| `1` | 出库账号（可指定数量，FIFO，自动复制到剪贴板） |
| `2` | 查找账号（子串匹配，先查库存再查出库历史） |
| `q` | 退出 |

也可按 `Ctrl+C` 退出。

### 录入格式

一行一条，字段用四个连字符 `----` 分隔：

```
账号----密码----邮箱----邮箱密码----网址
```

- **前两段必填**：账号、密码
- **后三段可选**：邮箱、邮箱密码、网址
- 中间字段缺失时用空段占位，例如仅有网址：`user----pass--------https://example.com`
- 网址不做格式校验，接受任意字符串

示例：

```
user001----pass123
user002----pass456----mail@example.com----mailpass
user003----pass789--------https://example.com
```

#### 批量入库

选择 `[0]` 后，可一次粘贴多行账号，**每行一条**，输入**空行**结束：

```
请输入账号信息（每行一条，输入空行结束）：
user001----pass123
user002----pass456
（空行回车结束）
```

- 合法行会立即入库；格式错误、库存重复、本批次内重复的行记为失败
- 部分失败不影响已成功入库的条目
- 全部处理完成后输出汇总及失败明细
- 若有失败条目，**自动将失败行的原始内容**（不含错误说明）复制到剪贴板，便于修正后重新粘贴

单条录入：输入一行 → 回车 → 再按一次回车（空行）结束。

### 重复账号处理

| 情况 | 行为 |
|------|------|
| 账号已在**库存**中 | 记为失败，不可覆盖 |
| 账号曾在**出库记录**中 | 进入待确认列表，需手动批准或取消 |
| 本批次内**同名重复** | 第二条及以后记为失败 |

#### 出库历史待确认

批量入库时，若某行账号曾出现在出库记录中，会进入待确认列表。界面默认为 **键盘操作模式**（Windows 控制台）；按 **`:`** 可进入 **命令模式** 输入文本命令。

```
以下 3 个账号曾出现在出库记录中，需确认是否入库：

  > [x] userA  （最近出库：2026-05-30 14:22:01）
      [ ] userB  （最近出库：2026-05-29 10:00:00）
      [ ] userC

操作：↑↓ 移动  空格/回车 切换选中  Y 批准选中  N 取消选中  Esc/Q 结束
命令：按 : 进入命令模式（a/c/a all/done/list）
```

#### 键盘操作模式（默认）

| 操作 | 说明 |
|------|------|
| ↑ / ↓ | 移动光标（循环首尾） |
| 空格 / 回车 | 切换当前条目的选中状态（`[x]` / `[ ]`） |
| Y | 批准所有已选中条目入库 |
| N | 取消所有已选中条目 |
| Esc / Q | 等同 `done`：剩余条目全部视为取消并退出 |
| 无选中时按 Y/N | 提示「请先选中条目」 |

#### 命令模式（按 `:` 进入）

按 **`:`** 进入命令模式，底部出现 `命令 > ` 提示符。输入文本命令后回车执行；按 **Esc** 取消并返回键盘操作模式。

| 命令 | 说明 |
|------|------|
| `a <序号>` | 批准指定序号（如 `a 1,3` 或 `a 1 3`） |
| `c <序号>` | 取消指定序号 |
| `a all` | 批准全部待确认条目 |
| `done` | 未处理条目全部视为取消 |
| `list` | 重新显示列表 |

- 循环直到待确认列表为空，或按 Esc/Q / 输入 `done` / `a all`
- 非 Windows 平台键盘模式不可用，界面始终为命令模式（`命令 > ` 提示符）

### 出库

- 无库存时提示「当前无库存，无法出库」
- 有库存时提示输入出库数量（直接回车默认为 **1**）
- 数量须为正整数；非法输入返回首页，不出库
- 若请求数量大于当前库存，按 **min(数量, 库存)** 出库，不报错
- 按 FIFO 取出账号，**逐行打印**，剪贴板内容为多行（`\n` 分隔，一行一条）
- 出库 0 条时不复制剪贴板

### 查找

选择 `[2]` 后输入查找字符串（直接回车返回首页）。

- 在账号、密码、邮箱、邮箱密码、网址五个字段中做**子串匹配**（任意字段命中即可）
- **先查库存**：有命中则逐条显示，标注 `【库存】`
- 库存无命中时**再查出库历史**，标注 `【出库历史】`
- 两表均无结果时提示「未找到匹配的账号」
- 查找 `%`、`_` 等特殊字符时按字面量匹配，不会当作 SQL 通配符

## 项目结构

```
.
├── main.py              # 入口：初始化数据库并启动 CLI
├── cli.py               # 交互菜单、批量录入/出库/查找、待确认多选
├── clipboard.py         # Win32 剪贴板 + tkinter fallback
├── console_input.py     # 控制台按键读取（Windows）
├── database.py          # SQLite 读写与查找
├── batch.py             # 批量入库分类逻辑（可测试）
├── parser.py            # 账号行解析与格式化
├── test_verification.py # 自动化验证脚本
└── data/
    └── accounts.db      # 运行时自动创建
```

## 数据存储

数据库文件：`data/accounts.db`

| 表名 | 用途 | 主要字段 |
|------|------|----------|
| `accounts` | 当前库存 | `username`（唯一）、`password`、`email`、`email_password`、`url`、`created_at` |
| `outbound_records` | 出库历史 | 账号信息（含 `url`）+ `inbound_at`（原入库时间）、`outbound_at`（出库时间） |

## 测试

```bash
python test_verification.py
```

脚本在临时数据库中运行，覆盖库存计数、重复拦截、FIFO 出库、批量入库/出库、出库历史待确认、5 段格式解析、子串查找、失败剪贴板辅助函数等场景。全部通过则退出码为 0。
