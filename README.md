# account-inventory-cli

> 账号出入库管理 — A Python CLI for account inventory management.

命令行工具，用于管理账号库存：录入账号、按先进先出（FIFO）出库，并将出库内容自动复制到剪贴板。

## 克隆

```bash
git clone https://github.com/HKLHaoBin/account-inventory-cli.git
cd account-inventory-cli
pip install -r requirements.txt
python main.py
```

## 功能

- **库存展示**：主菜单显示当前库存数量
- **账号录入**：支持 `----` 分隔格式，2～5 段字段；含入库粘贴与出库粘贴两种录入
- **FIFO 出库**：按入库时间取出最早账号，格式化输出并复制到剪贴板
- **重复检查**：库存内账号直接拒绝；曾出库账号需二次确认
- **出库历史**：每次出库写入历史记录，保留入库/出库时间
- **失败复制**：批量录入结束后，自动将失败条目的原始行复制到剪贴板
- **账号查找**：子串匹配，先查库存再查出库历史；唯一库存命中时可确认出库该条（非 FIFO）

## 环境要求

- Python 3.10+
- 标准库（SQLite 等）+ [pyperclip](https://pypi.org/project/pyperclip/)（剪贴板复制）

python main.py

## 使用说明

启动后进入交互菜单：

| 选项 | 说明 |
|------|------|
| `0` | 录入账号（子菜单：入库录入 / 出库粘贴录入，多行批量，空行结束） |
| `1` | 出库账号（可指定数量，FIFO，自动复制到剪贴板） |
| `2` | 查找账号（子串匹配，先查库存再查出库历史） |
| `Esc` | 退出（也可按 `Ctrl+C` 退出） |

### 持续模式与返回首页

选择 `[0]`、`[1]` 或 `[2]` 后进入对应**持续模式**：完成一次录入、出库或查找后**不会自动返回主菜单**，可继续在同一模式下操作。

选择 `[0]` 后先进入**录入子菜单**，选择 `[1] 入库录入` 或 `[2] 出库录入`，再进入对应持续粘贴模式；**Esc** 可从子菜单或粘贴模式返回首页。

| 模式 | 单次操作完成后 | 退出返回首页 |
|------|----------------|--------------|
| 录入 `[0]` → 入库 | 输出汇总后继续等待下一批（空行仍表示**结束本批次**） | Esc |
| 录入 `[0]` → 出库粘贴 | 输出汇总后继续等待下一批 | Esc |
| 出库 `[1]` | 出库成功后继续提示数量 | Esc |
| 查找 `[2]` | 显示结果后继续提示查询 | Esc |

- 在提示处按 **Esc** 返回首页；按 **Ctrl+C** 退出整个程序

以下情况**不退出模式**，仅提示后重新等待输入：

- 出库非法数量 → 提示后重试
- 出库无库存 → 提示后等待（可 Esc 退出）
- 查找空字符串 → 提示后重试
- 录入空批次（未输入任何行就空行）→ 忽略，继续等待下一批

待确认子界面（出库历史二次确认）中 **Esc** 的语义不变：仅结束待确认列表；本批次汇总输出后**仍留在录入模式**。

### 录入格式

一行一条，字段用四个连字符 `----` 分隔：

```
账号----密码----邮箱----邮箱密码----网址
```

- **前两段必填**：账号、密码
- **后三段可选**：邮箱、邮箱密码、网址
- 中间字段缺失时用空段占位，例如仅有网址：`user----pass--------https://example.com`
- 网址不做格式校验，接受任意字符串

示例：

```
user001----pass123
user002----pass456----mail@example.com----mailpass
user003----pass789--------https://example.com
```

#### 批量入库

选择 `[0]` → `[1] 入库录入` 后，可一次粘贴多行账号，**每行一条**，输入**空行**结束：

```
请输入账号信息（每行一条，输入空行结束）：
user001----pass123
user002----pass456
（空行回车结束）
```

- 合法行会立即入库；格式错误、库存重复、本批次内重复的行记为失败
- 部分失败不影响已成功入库的条目
- 全部处理完成后输出汇总及失败明细
- 若有失败条目，**自动将失败行的原始内容**（不含错误说明）复制到剪贴板，便于修正后重新粘贴

单条录入：输入一行 → 回车 → 再按一次回车（空行）结束。

#### 批量出库粘贴

选择 `[0]` → `[2] 出库录入` 后，可一次粘贴多行账号，**每行一条**，输入**空行**结束：

```
请输入出库账号信息（每行一条，输入空行结束）：
user001----pass123
user002----pass456
（空行回车结束）
```

| 情况 | 行为 |
|------|------|
| 账号在**库存**中 | 立即出库（使用库存字段，从库存移除） |
| 账号不在库存、也不在出库记录 | 直接写入出库历史（使用粘贴行字段） |
| 账号已在出库记录且不在库存 | 记为失败：「已在出库记录中」 |
| 本批次内**同名重复** / 格式错误 | 记为失败 |

- 部分失败不影响已成功出库的条目
- 全部处理完成后输出汇总及失败明细
- 若有失败条目，**自动将失败行的原始内容**复制到剪贴板；成功行不复制

### 重复账号处理

| 情况 | 行为 |
|------|------|
| 账号已在**库存**中 | 记为失败，不可覆盖 |
| 账号曾在**出库记录**中 | 进入待确认列表，需手动批准或取消 |
| 本批次内**同名重复** | 第二条及以后记为失败 |

#### 出库历史待确认

批量入库时，若某行账号曾出现在出库记录中，会进入待确认列表。界面默认为 **键盘操作模式**（Windows 控制台）；按 **`:`** 可进入 **命令模式** 输入文本命令。

```
以下 3 个账号曾出现在出库记录中，需确认是否入库：

  > [x] userA  （最近出库：2026-05-30 14:22:01）
      [ ] userB  （最近出库：2026-05-29 10:00:00）
      [ ] userC

操作：↑↓ 移动  空格/回车 切换选中  Y 批准选中  N 取消选中  Esc 结束
命令：按 : 进入命令模式（a/c/a all/done/list）
```

#### 键盘操作模式（默认）

| 操作 | 说明 |
|------|------|
| ↑ / ↓ | 移动光标（循环首尾） |
| 空格 / 回车 | 切换当前条目的选中状态（`[x]` / `[ ]`） |
| Y | 批准所有已选中条目入库 |
| N | 取消所有已选中条目 |
| Esc | 等同 `done`：剩余条目全部视为取消并退出 |
| 无选中时按 Y/N | 提示「请先选中条目」 |

#### 命令模式（按 `:` 进入）

按 **`:`** 进入命令模式，底部出现 `命令 > ` 提示符。输入文本命令后回车执行；按 **Esc** 取消并返回键盘操作模式。

| 命令 | 说明 |
|------|------|
| `a <序号>` | 批准指定序号（如 `a 1,3` 或 `a 1 3`） |
| `c <序号>` | 取消指定序号 |
| `a all` | 批准全部待确认条目 |
| `done` | 未处理条目全部视为取消 |
| `list` | 重新显示列表 |

- 循环直到待确认列表为空，或按 Esc / 输入 `done` / `a all`
- 非 Windows 平台键盘模式不可用，界面始终为命令模式（`命令 > ` 提示符）

### 出库

进入出库模式后，每次操作前显示当前库存。

- 无库存时提示「当前无库存，无法出库」，留在模式内等待（Esc 返回首页）
- 有库存时提示输入出库数量（直接回车默认为 **1**）
- 数量须为正整数；非法输入提示后重试，不出库
- 若请求数量大于当前库存，按 **min(数量, 库存)** 出库，不报错
- 按 FIFO 取出账号，**逐行打印**，剪贴板内容为多行（`\n` 分隔，一行一条）
- 出库 0 条时不复制剪贴板

### 查找

进入查找模式后，输入查找字符串（Esc 返回首页；空查询提示后重试，不退出模式）。

- 在账号、密码、邮箱、邮箱密码、网址五个字段中做**子串匹配**（任意字段命中即可）
- **先查库存**：有命中则逐条显示，标注 `【库存】`
- **唯一库存命中**：展示该条后询问是否出库（**非 FIFO**，按用户名出库该条）；输入 `Y`/`y` 确认出库并复制到剪贴板，空回车或 `N`/`n` 跳过；Esc 退出查找模式
- 库存命中 **2 条及以上**时仅列表展示，不询问出库
- 库存无命中时**再查出库历史**，标注 `【出库历史】`
- 两表均无结果时提示「未找到匹配的账号」
- 查找 `%`、`_` 等特殊字符时按字面量匹配，不会当作 SQL 通配符

## 项目结构

```
.
├── main.py              # 入口：初始化数据库并启动 CLI
├── cli.py               # 交互菜单、批量录入/出库/查找、待确认多选
├── clipboard.py         # pyperclip 剪贴板复制（含重试）
├── console_input.py     # 控制台按键读取（Windows + Unix Esc 支持）
├── database.py          # SQLite 读写与查找
├── batch.py             # 批量入库/出库分类逻辑（可测试）
├── parser.py            # 账号行解析与格式化
├── test_verification.py # 自动化验证脚本
└── data/
    └── accounts.db      # 运行时自动创建
```

## 数据存储

数据库文件：`data/accounts.db`

| 表名 | 用途 | 主要字段 |
|------|------|----------|
| `accounts` | 当前库存 | `username`（唯一）、`password`、`email`、`email_password`、`url`、`created_at` |
| `outbound_records` | 出库历史 | 账号信息（含 `url`）+ `inbound_at`（原入库时间）、`outbound_at`（出库时间） |
