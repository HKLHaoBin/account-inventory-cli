# account-inventory-cli

> 账号出入库管理 — A Python CLI for account inventory management.

命令行工具，用于管理账号库存：录入账号、按先进先出（FIFO）出库，并将出库内容自动复制到剪贴板。

## 克隆

```bash
git clone https://github.com/HKLHaoBin/account-inventory-cli.git
cd account-inventory-cli
python main.py
```

## 功能

- **库存展示**：主菜单显示当前库存数量
- **账号录入**：支持 `----` 分隔格式，2～4 段字段
- **FIFO 出库**：按入库时间取出最早账号，格式化输出并复制到剪贴板
- **重复检查**：库存内账号直接拒绝；曾出库账号需二次确认
- **出库历史**：每次出库写入历史记录，保留入库/出库时间

## 环境要求

- Python 3.10+
- 仅使用标准库（SQLite、`tkinter` 用于剪贴板）


## 使用说明

启动后进入交互菜单：

| 选项 | 说明 |
|------|------|
| `0` | 录入账号（支持多行批量，空行结束） |
| `1` | 出库账号（可指定数量，FIFO，自动复制到剪贴板） |
| `q` | 退出 |

也可按 `Ctrl+C` 退出。

### 录入格式

一行一条，字段用四个连字符 `----` 分隔：

```
账号----密码----邮箱----邮箱密码
```

- **前两段必填**：账号、密码
- **后两段可选**：邮箱、邮箱密码

示例：

```
user001----pass123
user002----pass456----mail@example.com----mailpass
```

#### 批量入库

选择 `[0]` 后，可一次粘贴多行账号，**每行一条**，输入**空行**结束：

```
请输入账号信息（每行一条，输入空行结束）：
user001----pass123
user002----pass456
（空行回车结束）
```

- 合法行会立即入库；格式错误、库存重复、本批次内重复的行记为失败
- 部分失败不影响已成功入库的条目
- 全部处理完成后输出汇总及失败明细

单条录入：输入一行 → 回车 → 再按一次回车（空行）结束。

### 重复账号处理

| 情况 | 行为 |
|------|------|
| 账号已在**库存**中 | 记为失败，不可覆盖 |
| 账号曾在**出库记录**中 | 进入待确认列表，需手动批准或取消 |
| 本批次内**同名重复** | 第二条及以后记为失败 |

#### 出库历史待确认

批量入库时，若某行账号曾出现在出库记录中，会进入待确认列表：

```
以下 N 个账号曾出现在出库记录中，需确认是否入库：
  [1] userA  （最近出库：2026-05-30 14:22:01）
  ...

命令：
  a <序号>     批准选中条目入库（如 a 1,3 或 a 1 3）
  c <序号>     取消选中条目（如 c 2）
  a all        批准全部待确认条目
  done         结束确认（未处理条目视为取消）
  list         重新显示列表

确认 >
```

- **批准**（`a`）：选中且仍待确认的条目入库
- **取消**（`c`）：选中条目记为失败
- **done**：未处理条目全部视为取消
- 循环直到待确认列表为空或输入 `done`

### 出库

- 无库存时提示「当前无库存，无法出库」
- 有库存时提示输入出库数量（直接回车默认为 **1**）
- 数量须为正整数；非法输入返回首页，不出库
- 若请求数量大于当前库存，按 **min(数量, 库存)** 出库，不报错
- 按 FIFO 取出账号，**逐行打印**，剪贴板内容为多行（`\n` 分隔，一行一条）
- 出库 0 条时不复制剪贴板

## 项目结构

```
.
├── main.py              # 入口：初始化数据库并启动 CLI
├── cli.py               # 交互菜单、批量录入/出库、剪贴板
├── database.py          # SQLite 读写
├── batch.py             # 批量入库分类逻辑（可测试）
├── parser.py            # 账号行解析与格式化
├── test_verification.py # 自动化验证脚本
└── data/
    └── accounts.db      # 运行时自动创建
```

## 数据存储

数据库文件：`data/accounts.db`

| 表名 | 用途 | 主要字段 |
|------|------|----------|
| `accounts` | 当前库存 | `username`（唯一）、`password`、`email`、`email_password`、`created_at` |
| `outbound_records` | 出库历史 | 账号信息 + `inbound_at`（原入库时间）、`outbound_at`（出库时间） |

## 测试

```bash
python test_verification.py
```

脚本在临时数据库中运行，覆盖库存计数、重复拦截、FIFO 出库、批量入库/出库、出库历史待确认、格式校验等场景。全部通过则退出码为 0。
